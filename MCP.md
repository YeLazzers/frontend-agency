# MCP — Инструменты агентства

## Подключены

### Context7 (`@upstash/context7-mcp`)
Актуальная документация по библиотекам. Используется всеми агентами при работе с любой библиотекой стека — React, TypeScript, TailwindCSS, shadcn/ui, Jotai, TanStack Query, Zod, Vite, Vitest, Storybook, React Router.

### GitHub (`@modelcontextprotocol/server-github`)
Работа с репозиториями: чтение кода, создание веток, коммиты, PR, ревью, issues.
- Токен хранится в `GITHUB_PERSONAL_ACCESS_TOKEN` (`.zshrc`)

---

## Потенциально полезны в будущем

### Figma MCP
Чтение дизайн-файлов. Architect и Engineer смогут получать структуру компонентов и токены прямо из Figma без ручного копирования.
Нужен: когда появится стабильный read API или официальный сервер от Figma.

### Playwright MCP (`@playwright/mcp`)
Браузерная автоматизация для QA-агента. Позволяет кликать, скриншотить, проверять поведение в реальном браузере — принципиально другой уровень QA по сравнению с code review.
Нужен: при написании `agents/qa.md` и настройке E2E-тестирования.

### Brave Search / Tavily
Веб-поиск для нестандартных кейсов: незадокументированные ошибки, CVE, редкие паттерны. Context7 покрывает библиотечные вопросы, этот MCP нужен для всего остального.
Нужен: если агенты начнут упираться в пробелы Context7.
